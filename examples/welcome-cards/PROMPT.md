# Prompt: SaaS Company Welcome Cards

The brief that produced `welcome-cards.html`. Paste it to Claude Code with this skill
installed to replicate the build. Note the closing line — the brief deliberately asks the
skill to **quiz** for the missing details before building (see `NOTES.md` for what surfaced).

---

Using the skill `salesforce-ui-prototype`. Start a new project called **SaaS Company
Welcome Card**. As the CEO of a software company, I want to send a welcome card by snail
mail to all my new accounts. I need a **home page for Welcome Cards** that keeps me updated
on cards awaiting approval and send, and maybe some other visuals. It's ok to use Lightning
components here. Then my **reps** need to see each new client added to a **queue**. They
need to verify the mailing address, and submit it — all **within 14 days of onboarding**.
**Every 30 days**, the list of new accounts is exported for printing. Additionally, after
assignment, they need to be added to a **Marketing Cloud journey** for new accounts that
drip-campaigns them onboarding information. Quiz me on what else I need to explain.

---
